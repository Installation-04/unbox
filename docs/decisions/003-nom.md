# ADR 003 : nom

Statut : proposé

Marque : Unbox. Nom technique : UnboxOS (le suffixe évite la noyade dans les résultats « unboxing »).
Alternatives écartées : Rune/RuneOS (déjà une distro Linux), Rbox (trop proche de Xbox).

## À faire avant publication
- Vérifier l'org GitHub (`unboxos`, `unbox-os`) et réserver un domaine (`unboxos.org`, `getunbox.org`, `unbox.gg`).
- Recherche de marque (OPIC, USPTO) en classe logiciels/jeux vidéo.
- Vérifier la confusion avec des projets existants nommés « unbox ».
